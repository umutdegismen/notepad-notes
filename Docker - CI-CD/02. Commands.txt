	
	
	The commands that we'll be using in common:
		
		GENERAL:
			docker version 												: prints the client and the server versions
			clear / ctrl+l												: cleans the screen
			docker 														: opens the commands list
			docker-compose version 										: output-> Docker Compose version v5.0.1 
		
		IMAGES:
			docker pull [IMAGENAME]										: pulls an image from DockerHub
			docker images 												: shows all the images in our machine
			docker rmi [IMAGENAME]/[IMAGEID]							: removes an image
			docker run -d [IMAGENAME]									: to run the container in the background
			docker run -i [IMAGENAME]									: to attach the standard input to the container
			docker run -t [IMAGENAME]									: to attach the standard output to the container
			docker run -it [IMAGENAME]									: runs the container in interactive mode. (like pretty keyword in cucumber-runner.class)
		
		CONTAINERS:
			docker ps													: shows all the running containers
			docker ps -a												: shows all the containers including stopped containers
			docker run [IMAGENAME]										: creates a container from an image
			docker start [CONTAINER_ID]									: starts the container again
			docker start -i [CONTAINER_ID]								: starts the container and enters in it
			docker stop [CONTAINER_ID] / [CONTAINER_NAME]				: stops a running container 
			docker rm -f [CONTAINER_ID]									: -f flag'i force demek, container calisiyor olsa bile direkt siler.
			docker rm [CONTAINER_ID]									: container calismiyorsa siler. Calisiyorsa, once "docker stop containerID" gerekli 
			docker exec -it [CONTAINER_ID] bash							: goes back inside the container tomorrow after stopping it today (yeni kapi acma)
			docker exec -it [CONTAINER_ID] sh							: use 'sh' instead of 'bash' when executing small images like alpine (yeni kapi acma)
			docker attach [CONTAINER_ID]								: eski kapiya geri donme
			[ctrl + p + q]												: interactive moddan cikar (container calismaya devam eder)
			docker system prune -f										: removes all the stopped containers (docker doesn't touch the running containers)
			docker system prune -a										: removes all the stopped containers (docker doesn't touch the running containers) + UNUSED IMAGES
			docker logs [CONTAINER_ID / CONTAINER_NAME]					: prints the console output (let's say we run the container and printed the output 
																		  and cleared the screen with 'clear' command but we want to see the output again.
																		  By using this command, we can see the log output again without creating another container)
			docker run -d --name [SOME_NAME] nginx						: to assign a new name to the container (-d is to run in the background)
			docker run -it --entrypoint=/bin/bash						: Entrypoint is the command to be executed once a container is created.
																		  An image might have an entrypoint already.
																		  This option overrides the container's entrypoint.
		
		NETWORK:
			docker network ls											: lists the created networks
		
		VOLUME MAPPING:
			docker run -v /HostPath/folderName:/ContainerPath/folderName [imageName]	
																										: Creates a volume map between the local folder and the container folder.
																											Whatever you add in the local folder, you see it in the container folder, whatever you add in the container folder, you see it in the local folder.
		
		DOCKER COMPOSE:
			docker compose up															: Runs the services/images declared in the compose.yaml file
			docker compose up -d													: Runs the services/images declared in the compose.yaml file in background.
			docker compose down														: Stops all running services/images declared in the compose.yaml file
			docker compose up --scale [browser-name]=3		: Sets up the scale of the service (browser)-(deploy/replicas).
																											How many browsers you want to run in parallel, you set it up with this code, or through the yaml file.
			docker compose up --scale chrome=2 --scale firefox=2 -d	
																										: Sets up the scale of more than one services/images. 
																											For each service, you need to specify it's own "--scale".
			docker compose ps															: List of running services/images		
		
		
		CURL:		
			This is mostly used to apply an auto wait to nodes. Curl command pulls the response using JSON format.
			So, we can avoid "SessionNotCreatedException" by using "ready: true" property.
		
			winget install jqlang.jq											: Downloads and installs "jq" package manager/CLI tool on Windows.
			curl http://localhost:4444/status							: Displays raw (unformatted) JSON status of Selenium Grid, along with curl download progress.
			curl -s http://localhost:4444/status | jq			: Displays status in formatted/pretty JSON (via jq) in SILENT mode (hides curl progress).
			curl -sS http://localhost:4444/status | jq		: Formatted JSON only + shows network errors if Grid is down (Best practice).
			curl http://localhost:4444/status | jq				:	Displays formatted/pretty JSON, but includes curl's download progress output alongside it.
			curl -sS http://localhost:4444/status | jq .value 			 		: Displays only the value of "value" key from the json response.
			curl -sS http://localhost:4444/status | jq .value.ready  		: Displays only the value of "ready" key from the json response.
			curl -sS http://localhost:4444/status | jq .value.message 	: Displays only the value of "message" key from the json response.
			curl -sS http://localhost:4444/status | jq -r .value.browser: Removes the quotation marks. --- output : chrome instead of "chrome"
			
		Installing JQ or Curl to a container:
			1. Create a container of an Image in interactive mode :	docker run -it bellsoft/liberica-openjdk-alpine
			2. Check if Curl or jq is installed										: type 'jq' or 'jq --version'
																															type 'curl' or 'curl --version'
      3. Install curl and jq																: apk add jq / apk add curl
																															(just typing 'apk' displayes the commands that can be used.)
			4. Check if Curl or jq is installed again.
