    Collection : Group of objects represented in a single unit

    Collection interface has 3 children:
        - List

                                Gets the index directly.
            * LinkedList    ->  stores the data in arrow shape. (ic-ice. matruska bebek gibi, yelpaze seklinde)
                                
        - Set
            *HashSet        ->  stores the data randomly.
            *LinkHastSet
        - Queue
        
    List: is an ordered collection that allows duplicates
    List interface is implemented in : ArrayList, LinkedList and Vector Classes

-> To overcome limitations of Arrays Collections Framework has been introduced.

        Collections will be dynamic in size
        Collections will have ready methods to manipulate the data
        Inside collections we can store/use only OBJECT

		LinkedList 
	   ------------

    * LinkedList - Class that implements the list interface and stores elements in a form of double linked objects
	* LinkedList is good for insertion and removal of elements (especially in the middle of the list)
	
	*** They both have INSERTION ORDER !! 
	
    WHY ??
		
		If you remove, or insert an object in the middle of the ARRAYLIST, java has to move all the elements after that to fill the empty index.
		
		But if you remove an object of an LINKEDLIST, Java finds the object directly by using index of the element and removes it.
		
		So, in big lists which has millions of objects in it, ARRAYLIST works slower.



	ArrayList vs LinkedList:
	
		1. 	ArrayList uses a dynamic array to store the elements/objects meanwhile LinkedList uses a doubly linked list 
			to store the elements/objects
		
		2. 	ArrayList is the best choice to retrieve data, LinkedList is the best choice to insert and remove data

													 ITERATOR
													----------

Iterator: Is used to iterate objects in all collections.

        STRUCTOR -> Iterator<Integer> it = numbers.iterator();  -> It iterates a specific list

	
    There are 3 methods in the Iterator class
		
		➔ it.hasNext();   	->  This method will return true/false. if there is a next element
		➔ it.next(); 		->  This method will return the next element from the list
		➔ it.remove();		->  This method will remove the current element from the list

		*How to sort a LinkedList descending:
		
			Iterator it = linked1.descendingIterator();
			while(it.hasNext()) 
			{
				System.out.print(it.next()+" ");
			}

                                                    SET INTERFACE
                                                  -----------------
       HASHSET
    ------------
                                                     
	- HashSet does NOT guarantee any insertion order
	- No Duplicates
	- Allows Null element

        STRUCTOR -> HashSet<String> strList = new HashSet<>();
        
    HashSet Methods
  -------------------
        
		➔ .add(Element e)		: It adds the element e to the list.
		➔ .clear()				: It removes all the elements from the list.
		➔ .contains(Object o)	: It checks whether the specified Object o is present in the list or not. 
									If the object has been found it returns true else false.
		➔ .isEmpty()			: Returns true if there is no element present in the Set.
		➔ Iterator iterator()	: Used to return an iterator over the element in the set.
		➔ .size()				: It gives the number of elements of a Set.
		➔ .remove (Object o)	: It removes the specified Object from the Set.
		➔ .clone()				: This method returns a shallow copy of the HashSet.

		➔ NOTE: A Set doesn't provide any method for data retrieval.
		 


    LINKEDHASHSET
    --------------
    
	- LinkedHashSet keeps insertion order
	- No Duplicates
	- Allows Null element 
    
    
     TREESET
    ---------

	- TreeSet SORTS the elements in ASCENDING order
	- No Duplicates
	- Does NOT allow Null element
