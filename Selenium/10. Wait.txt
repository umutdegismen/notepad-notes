~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

	
	-IMPLICIT WAIT:  
	
	*What it does: 	While trying to find an element, we say, do not give up for 10-15 sec before throwing an exception
	
		Is a way to tell the driver that when finding the elements (only using findElement and findElements) and they are not immediately there, to wait for some time. If they are not there even after the waiting time, then throw exception. 

	We have been using implicit wait of 0 seconds. 
	You can set a new implicit wait time:
	
	driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(20));

	If element is found before reaching the end of the set time, then the remaining time is ignored the execution proceeds. 


~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


	-EXPLICIT WAIT: 
	
		WebDriverWait
	   ~~~~~~~~~~~~~~~
	   
		Is used to tell the driver to wait for specific conditions to happen. When the time to wait is reached and the conditions has not happened yet, then exception is thrown. 

	WebDriverWait works with ExpectedConditions class

	How to use it: 

	WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(15));
	wait.until(ExpectedConditions.--------);
	
	
	// wait.until(ExpectedConditions.visibilityOfElementLocated(By.id("button1")));
	OR 
	// wait.until(ExpectedConditions.visibilityOf(driver.findElement(By.id("button1"))));

	FLUENT WAIT: 
  ~~~~~~~~~~~~~~~	
  
		Is used to tell the web driver to wait for a condition, as well as the frequency with which we want to check the condition before throwing an exception.

	How to use it:

		FluentWait wait = new FluentWait(driver);
		wait.withTimeout(Duration.ofSeconds(30));
		wait.pollingEvery(Duration.ofSeconds(1));
		wait.ignoring(NoSuchElementException.class);
