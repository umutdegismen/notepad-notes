
	
	Different ways of clicking:
	
		1. Regular selenium click method
			
			element.click();
			
		2. JavascriptExecuter click method
			
			JavascriptExecutor js = (JavascriptExecutor) driver;
			js.executeScript("arguments[0].click()",driver);
			
		3. Actions click method
			
			Actions action = new Actions(driver);
			WebElement searchBox = driver.findElement(By.id("twotabsearchtextbox"));
			action.moveToElement(searchBox).click();
			
		4. dispatchEvent()
		
			Let's say, you have a button on a page that has a click event listener attached via JavaScript, but element.click() doesn't work due to it being overlapped or styled in a way that blocks interaction.
			
			dispatchEvent() is a JavaScript method used to manually fire an event on a DOM element. It doesn’t "call a method" in the traditional sense, and it doesn’t "force" the element to do anything physically — instead, it tells the browser:

			“Hey, pretend this element just had a user interaction — like a click, input, or change — and run whatever JavaScript is listening for that event.”
			
				WebElement button = driver.findElement(By.id("myButton"));
				JavascriptExecutor js = (JavascriptExecutor) driver;
				js.executeScript(
					"let event = new MouseEvent('click', {" +
					"  bubbles: true," +
					"  cancelable: true" +
					"});" +
					"arguments[0].dispatchEvent(event);", 
					button
				);
