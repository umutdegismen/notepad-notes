	BASIC GIT COMMANDS
	
		➔ cd .. 									--> Step out of current director
		➔ pwd 										--> Get the current folder details
		➔ git rev-parse --show-toplevel  			--> Repo root'u neresi?
		➔ cd folderName 							--> Move into a sub-folder	
		➔ ls 										--> List the files in the current folder (same as 'dir')		
		➔ ls -al									--> List the files in DETAILED (creating time-who created-when created..)	
		➔ rm -rf folderName							--> Removes a specific FOLDER	
		➔ rm fileName.txt							--> Removes a specific FILE	
		➔ git mv old-name.txt new-name.txt.			--> Renames a specific FILE
		
		~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

		➔ mkdir + "name of the folder to Create"	--> Create a new folder
		➔ vim FileName.txt 							--> create a text file
		➔ Press “I” to Insert 						--> This will allow you to edit text file
		➔ Press “ESC” 								--> You will exit from text file
		➔ Press “:wq” 								--> when you enter this line this will write and quit.
	
		~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
		
		➔ dir -> powershell

			git log ---> looking at history

			git clone ---> cloning a project from gitHub to my local pc
							- will have its own local repository
							
						- copies the online repository and brings it as local repository
						- provides the working area
						
			git fetch ---> will update your local repository with the latest commits in the remote repository 

			git pull  ---> will update your local repository and working area with the latest commits in the 
							remote repository
			
						
							
			git stash ---> 

				Situation: I am working on a feature, but a coworker has pushed some new functionality on the remote 
				repository. I want to pull those changes, fix something quick and then push 
				BUT I DONT WANT TO SEND THE CURRENT FEATURE IN PROGRESS!!!
				
				- we use git stash to temporary store changes we have made in the working area
				- after we are done we can get those changes back and continue working on them 
				
			- git stash 				--> will stash the modifications (does not include new (untracked) file)
			- git stash pop 			--> will apply back the latest stashed changes
			- git stash pop stash@{1}
			- git stash clear 			--> clear all the stashes

			- git stash --include-untracked
