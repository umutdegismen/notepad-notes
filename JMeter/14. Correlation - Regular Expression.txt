
	
	Correlation and implementing Regular expressions to it:
	--------------------------------------------------------
	
	In JMeter, correlation refers to the process of handling dynamic data that is generated by a previous request and then used in subsequent requests during a performance test. Many web applications generate dynamic values, such as session IDs, tokens, or user IDs, which need to be captured from server responses and reused in later requests. 
	
	login islemi gerektiren projelerde, birden fazla test data'si gonderdigimizde, server'dan unauthorized hatasi aliriz. Bunun onune gecmek icin "Correlation"dan yardim aliriz. 
	
	Yapacagimiz olay kisaca su:
		
		Response Body kontrol et, name="userSession" value="(.+?)" satirinda 'value'nun karsiligi olan en kısa eşleşmeyi al, olusturdugun 'sessionId' variable'ina ata. Daha sonra bu variable'i, 'Login' HTTP Request'inde data 'userSession' datasina ${sessionId} seklinde deger olarak gonderecegiz.
	
	Yapacagimiz adimlar soyle;
		
		1. Oncelikle dinamik session Id hangi requestte olusturuluyor onu bulmamiz lazim. Developer'a da sorabilirsin. 
			Dynamic session Id olusturuluyor, hangi request olusturuyor olabilir ? diye developer'a sorabilirsin. 
			
		2. 'Get Session' adinda bir HTTP request olustur.
			Tum alanlari doldur diger HTTP request'ler gibi.
			Protocol/Server Name/Port Number/ HTTP Request(HTTP Method)/Path etc.
			
		3. Olusturdugun 'Get Session' altina 'Regular Expression Extractor' olustur.
			right-click / Add / PostProcessor / Regular Expression Extractor
			
		4. Ilgili alanlari doldur.
			
			- Name of created variable	:	sessionId	(cektigimiz sessionId'yi bu variable ile kaydedecegiz)
			- Regular Expression		:	name="userSession" value="(.+?)" 
			
								
				Testi run ettigimiz zaman Get Session request'inde Response Body'yi kontrol ediyoruz. 
				
				<name="userSession" value="0AA"> session Id olusturuldugunda 'value' tag'i icine kaydediliyor. Dolayisiyla, bu value tag'inde "(.+?)" regular expression'i kullanacagiz.
				
				"(.+?)" ifadesi, tırnak işaretleri arasındaki en kısa metni yakalar. Yani, no matter what value you get, go and grab it.
				
				. → Herhangi bir karakter (satır sonu hariç).

				+ → Bir veya daha fazla tekrar.

				? → "lazy" yani "en kısa eşleşmeyi bul" anlamına gelir.
			
			
			- Template ($1$ where is capturing group number, starts at 1) :	 $1$
				
				Regular Expression:	name="userSession" value="(.+?)" kisminda, kac adet grup gonderiyorsak, burada onu belirtiyoruz. 
				
				Ornegin, name="(.+?)" value="(.+?)" id="(.+?)" olsaydi, Template: $3$ olacakti. Ya da hangisinden deger alacaksak onu belirtiyoruz.
				
			- Match No : 1
				Bizim ornegimizde tek grup var o yuzden 1 yaziyoruz.
				
		5. 	'Login' HTTP Request'inde 'userSession'a deger olarak dinamik deger atiyoruz ki otomatik sekilde olarak gonderebisin server'a.
			
				${sessionId} seklinde.
			
			
			
		Tum bu ayarlardan sonra testi run ettigimizde sorunsuz sekilde login problemi yasamadan testimiz kosulacak.
